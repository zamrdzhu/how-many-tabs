How many tabs do you have open? **366** — one for every day of a leap year.

A year of opening "I'll read this later" and never closing any of it: articles, docs, half-finished forms, a recipe from February, the same video essay queued three times. This program answers the question the only honest way it can — with a single number, digits only, no words, no explanation.

## Why 366?

A tab count has to do three things at once: surprise, stay believable, and hint at a life behind it. A round thousand reads as made up; a single digit reads as a fresh install. 366 is specific enough to be a real count — nobody invents 366 — high enough to surprise, low enough that a real tab hoarder could genuinely have it open right now, and it carries its own story without a word of explanation: one tab saved per day, for a whole leap year, none of them ever closed.

## Run it

```sh
node main.ts
```

It writes the count to `/output/entry.txt` (exactly `366`, 3 bytes, no trailing newline) and verifies on disk that the file holds one 1–5 digit number.
